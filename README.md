Laundry Service Landing Page (task_5)

A static front‑end landing page for a premium laundry service. It presents the brand with a clean header, a call‑to‑action section, and a representative image – designed to attract users to book a service.


 How to Run

1. Clone or download this repository to your local machine.

2. File structure must keep `index.html` and `style.css` in the same folder.

3. Open`index.html` in any modern web browser.


 Purpose

 Its goals are:

- Introduce the service with a compelling headline and brief description.
- Capture user interest through a prominent “Book a service today!” button.
- Build trust by displaying a high‑quality interior image of the laundry facility.
- Provide navigation to other sections (Home, Service, About us, Contact Us) and a user account button.

  Comstraints:
- use viewpoints(vh,vw) for it to adapt tp screen size
- no flexbox used.
- Page not to go in scroll.
