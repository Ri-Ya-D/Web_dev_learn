Product Description
This project provides a practical demonstration of CSS selector specificity and styling concepts using an index.html file and an external style.css file. The HTML document contains a structured layout with various elements—headings, paragraphs, links, and lists—each styled using a combination of element selectors, class selectors (.head), and ID selectors (#bglime, #para). The primary goal is to visually showcase how different CSS rules interact and override each other based on specificity and the cascade order.

How to Use
1.Download the files: Ensure index.html and style.css are saved in the same folder.
2.Open the HTML: Double-click index.html to open it in your desired web browser.

Documentation of Purpose
This project was designed to fulfill a specific task: demonstrating the importance of CSS selectors and how they influence the visual representation of an HTML document. It covers several key concepts:

1.Element Selectors: Such as p and article for broad styling.
2.Class Selectors: Like .head to group multiple elements.
3.ID Selectors: Such as #bglime and #para for unique, high-specificity styling.
4.Specificity Rules: Showing that inline styles (or a higher specificity ID) will override class or element-level styles.
5.Tag Wrapping: Exploring how elements like <label>, <span>, <article>, and <aside> are styled both by their own element selectors and when wrapped around other content.
6.The project also serves as a baseline for beginners to experiment with CSS, modify values, and immediately see the impact on the web page.
