Laundry Mart - Static Website
Project Description
This is a simple, static HTML webpage for Laundry Mart – an online laundry service provider. It showcases the company's services, price list, and a basic booking form & Contact info. 

Features
1.Header with a welcome message and description of the service.

2.Services list (washing, ironing, dry-cleaning, pickup/dropoff, etc.).

3.Price table with different rates based on fabric weight (GSM).

4.Booking form with fields for name, email, and phone number.

5.Contact information in the footer (email and phone).

How to Run
1.Download or clone the repository.

2.Navigate to the folder containing index.html.

3. Click on it and it will nativate to a web browser


Purpose & Learning Outcomes (based on the understanding in doubt clearing)
This project serves as a practical exercise to understand and apply basic HTML concepts, including:

1.Document structure (<!DOCTYPE>, <html>, <head>, <body>)

2.Text formatting (<h1>, <h2>, <pre>, <b>)

3.Lists (<ul>)

4.Tables (<table>, <thead>, <tbody>, <tfoot>, <th>, <td>, rowspan, colspan)

5.Forms (<form>, <label>, <input>, <button>)

6.Images (<img>)

7.Links (<a> for mailto and tel)

8.Semantic grouping (<footer>)
